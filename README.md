# Celebrity Search Editor

Create and edit Google-style celebrity search result pages, Instagram posts and profiles, and Tiktok profiles. Everything runs in your browser with no account needed.

## Features

- **Edit text directly** - Click most text on the preview to change it
- **Replace images** - Click any image placeholder to add your own photos
- **Image library** - Save images and reuse them across your project
- **Undo/Redo** - Go back with Ctrl+Z or forward with Ctrl+Shift+Z
- **Export as PNG** - Download your finished design as an image (this may take a moment)
- **Save/Load projects** - Export your work as a JSON file and import it later
- **Works offline** - All data stays on your computer

## How to Use

### Edit Text

1. Use the **Variables panel** on the left to type in details (name, age, occupation, etc.)
2. Or click directly on text in the preview to edit it
3. Press Enter or click away to save

(You may have to reload the page to get some of the text showing properly. Don't worry, the rest of the project will still be there, it just re-renders the text)

### Add Images

1. Click any "Click to add" placeholder or existing image
2. Select an image from your computer (PNG, JPEG, or WebP)
3. The image appears automatically and is saved locally

### Use the Image Library

1. Click **Add Image** in the Image Library panel
2. Upload images you want to reuse
3. Drag and drop an image into a slot to apply it
4. Hover over library images and click × to delete (this also removes them from any slots they've been placed in)

### Undo/Redo

- **Undo**: Click the Undo button or press Ctrl+Z / Cmd+Z
- **Redo**: Click the Redo button or press Ctrl+Shift+Z / Cmd+Shift+Z

### Export Your Work

- **Export PNG**: Downloads your design as a high-quality image
- **Export Project**: Saves everything as a JSON file (includes text and images)
- **Import Project**: Loads a previously saved project

### Reset

Click **Reset Template** to start fresh with the default template (this deletes all your changes).

## Running the App

If you've copied the source code, simply open `index.html` in your browser. No installation required.
